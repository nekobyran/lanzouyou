# LanzouYOU

Private Android source mirror and release channel. Build with:

``powershell
pwsh -File command/Invoke-FlutterClient.ps1 -Action BuildAndroidRelease
``

Replace the APK release asset with command/Sync-LanzouYOUGitHubApk.ps1.
